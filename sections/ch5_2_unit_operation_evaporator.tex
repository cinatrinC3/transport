\subsection{蒸發器 Evaporator}
藉由加熱使溶劑因沸騰而汽化，以去除溶劑達到溶液純化的目的\\
只能用在一個會揮發另一個\fbox{不會揮發}的混合物\\
常用於食品工業(果汁、牛奶)、製藥工業(抗生素、維他命)、化學工業(鹽水濃縮、硫酸濃縮)
\begin{itemize}
  \item 蒸發器不希望發生的兩件事:
  \begin{enumerate}
    \item 結垢(Fouling)\\
    會使熱傳效果變差($k_{\text{fouling}}$很小)，所以$U,Q$都變小\\
    增加操作成本\\
    解決方法: 選擇適當的蒸發器種類、定期清洗
    \item 泡沫(Formation of foam)

    會使液體帶入蒸氣中，造成物料損失\\
    解決方法: 選擇適當的蒸發器種類、加裝擋板
  \end{enumerate}
  \item 蒸發器的種類
  \begin{enumerate}
    \item 橫管式蒸發器:
    \begin{itemize}
      \item 水蒸氣於管內流動、溶液於管外流動
      \item 自然對流的加熱方式，加熱效果較差，高黏度流體效果更差
      \item 不適用易產生泡沫或結垢的流體
      \item 構造簡單、價格低廉、適合小規模生產
    \end{itemize}
    \item 垂直短管式蒸發器
    \begin{itemize}
      \item 水蒸氣於管外流動，溶液於管內流動，濃縮液則由底部流出
      \item 自然對流的加熱方式，可加裝擋板以消除泡沫，並增加對流效果
      \item 適用於易產生泡沫的流體，但結垢仍然不行
      \item 構造簡單，價格不貴
    \end{itemize}
    \item 垂直長管式蒸發器
    \begin{itemize}
      \item 水蒸氣於管外流動，溶液於管內流動，濃縮液則由底部流出
      \item 自然對流的加熱方式，但因為很長，熱傳效果更好
      \item 溶液只要經管一次，即可完成蒸發的目的，大幅縮短加熱時間
      \item 適用於易產生泡沫的流體、對溫度敏感的流體、同樣不適合用在易結垢的
      \item 不適合用在會有鹽類析出、黏度高的流體
    \end{itemize}
    \item 強制循環式蒸發器
    \begin{itemize}
      \item 水蒸氣於管外流動，溶液於管內流動，濃縮液則由底部流出
      \item 加裝循環泵浦作為融業的強制循環、強制對流、熱傳效果更好、大幅縮短加熱時間
      \item 適用於易產生泡沫的流體、對溫度敏感的流體、黏度高的流體
      \item 由於氣液飛濺的情形嚴重、泵浦的動力消耗、成本較高
    \end{itemize}
    \item 夾套式蒸發器(攪膜蒸發器)
    \begin{itemize}
      \item 唯一一種不會有水垢的問題
      \item 中央有一個旋轉刮刀，會把進料物流全部撥到牆面，形成薄膜向下流
      \item 垢雖會生成於牆面，但不會妨礙蒸氣的熱傳
      \item 適用於易結垢、高黏度、對溫度敏感的流體
      \item 成本高、操作困難
    \end{itemize}
  \end{enumerate}
  \item 蒸發器的名詞介紹
  \begin{itemize}
    \item 蒸發量(Capacity),$V$:\\
    單位時間所\fbox{去除溶劑}的質量(H2O kg/hr)\\
    肯定是越大越好\\
    濃縮液濃度也會上升，效果好
    \item 蒸氣使用量(Steam Consumption),$S$:\\
    單位時間，蒸發器使用(消耗)的蒸氣質量(use H2O(g) kg/hr)\\
    因為蒸氣很貴，越小越好，為\fbox{成本}
    \item 經濟效益(Economy),$\eta$:\\
    每使用單位質量蒸氣，所能去除溶劑的質量
    \begin{equation}
      \eta = \frac{V}{S}
    \end{equation}
  \end{itemize}
  蒸發器的設計方程可以歸類成:

    每條物流都分別標註，流量、組成、溫度、焓值(液體小寫$h$, 蒸氣大寫$H$)\\
    P.S. 組成是指欲濃縮物料的濃度\\
    蒸氣熱源不含物料，沒有泡泡生成蒸氣輸出也不含物料\\
    蒸氣進入蒸發器後，溫度不變，提供汽化熱，冷凝成冷凝水，焓值變小
    \begin{itemize}
      \item 整體質量平衡:
      \begin{equation}
        F+S = S+V+L \implies F=V+L
      \end{equation}
      \item 溶質質量平衡:
      \begin{equation}
        F x_F + S\cancel{x_S}  = S\cancel{x_S} + L x_L + V \cancel{x_V} \implies F x_F = L x_L
      \end{equation}
      \item 熱平衡(找到由水蒸氣提供的熱量):\\
      進來的總能量=出去的總能量
      \begin{equation}
        F\cdot h_F + S\cdot H_S = S\cdot h_S + L\cdot h_L + V\cdot H_V
      \end{equation}
      解得:
      \begin{equation}
        F h_F + S(H_S - h_S) = L h_L + V H_V
      \end{equation}
      定義$\lambda$為蒸氣的潛熱
      \begin{equation}
        \lambda = H_S -h_S
      \end{equation}
      代入上式得:
      \begin{equation}
        F h_F + S\cdot \lambda = L h_L + V H_V
      \end{equation}
      \item 求出效率值:
      \begin{equation}
        \eta = \frac{V}{S} = \frac{H_S - h_S}{H_V - h_L} = \frac{\lambda}{H_V - h_L}
      \end{equation}
      \item 蒸發器的設計方程式\\
      由於蒸發器是一種\fbox{熱傳裝置}，故使用$U$來表示熱傳效果\\
      只要是熱傳裝置，如同熱交換器一樣，都會有綜合所有熱阻的$UA$值\\
      而此題蒸發器相當於1-1 shell and tube heat exchanger，所以
      \begin{equation}
        Q = \cancelto{1}{F_G} UA\text{LMTD}
      \end{equation}
      而且這個蒸發器的\\
      $\Delta T_\mcirc{1} = T_S - T_1$，$\Delta T_\mcirc{2} = T_S - T_1$\\
      P.S. 因為有攪拌，而且溫度入口並沒有直接碰到加熱管\\
      甚至還隔了氣液介面，所以都是$T_1$\\
      故LMTD要用L'Hopital's Rule計算 (\ref{eq:lmtd_evaporator_lhospital})
      \begin{align}
        \text{LMTD} &= \frac{\Delta T_{\mcirc{1}}-\Delta T_{\mcirc{2}}}
        {\ln\left(\frac{\Delta T_{\mcirc{1}}}{\Delta T_{\mcirc{2}}}\right)} \nonumber\\
        &=\frac{0}{0}\nonumber\\
        \xrightarrow[\text{L'Hopital's Rule}]{} \quad \Delta T_{\mcirc{1}} &= \Delta T_{\mcirc{2}} = T_S - T_1
      \end{align}
      最後設計方程式為:
      \begin{equation}
        Q = UA (T_S - T_1)
      \end{equation}
    \end{itemize}
