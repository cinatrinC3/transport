\subsection{單元操作介紹}
\begin{itemize}
  \item 單元操作(Unit Operation)是指在化工過程中\\
  將物料進行處理、轉換或分離的基本操作單位。\\
  這些操作通常涉及物理或化學變化，並且是工業生產過程中的重要組成部分。
  \item 常見的單元操作包括:
  \begin{enumerate}
    \item 反應器(Reactor): 用於進行化學反應的設備
    \begin{figure}[H]
      \centering
      \begin{tikzpicture}[>=Latex, line cap=round, line join=round, thick]
        \draw (0,0) rectangle (4,2);
        \node at (2,1) {反應器};
        \draw[->] (-2,1) -- (0,1);
        \node[anchor=east] at (-2,1) {A};
        \draw[->] (4,1) -- (6,1);
        \node[anchor=west] at (6,1) {A+B};
      \end{tikzpicture}
      \caption{反應器示意圖}
    \end{figure}
    \item 分離器(Separator): 用於將混合物分離成不同組分的設備
    \begin{figure}[H]
      \centering
      \begin{tikzpicture}[>=Latex, line cap=round, line join=round, thick]
        \draw (0,4) arc(180:0:1 and 0.5) -- (2,0) arc(0:-180:1 and 0.5) -- cycle;
        \node at (1,3) {分離器};
        \draw[decorate, decoration=snake, blue] (0,2) -- (2,2);
        \draw[->] (-1,2) -- (0,2);
        \node[anchor=east] at (-1,2) {A+B};
        \draw[->] (1,4.5) -- (1,5) -- (3,5) node[right] {B};
        \draw[->] (1,-0.5) -- (1,-1) -- (3,-1) node[right] {A};
      \end{tikzpicture}
      \caption{分離器示意圖}
    \end{figure}
    需要找到分離物質之間的矛盾點
    \begin{itemize}
      \item 蒸發性差異
      \begin{itemize}
        \item 揮發性高的成分容易蒸發，一個會揮發、一個不會\\
          使用蒸發(Evaporate)器(Evaporator)
        \item 都會揮發，但揮發性不同\\
          使用蒸餾(Distillation)器(Distiller)
      \end{itemize}
      \item 溶解度差異
      \begin{itemize}
        \item 氣體，以液體捕捉\\
          使用吸收(Absorb)塔(Absorption Tower)
        \item 液體，以氣體捕捉\\
          使用洗滌(Stripping)塔(Stripping Tower)
        \item 由一種液體，轉移到另一種液體\\
          使用萃取(Extract)器(Extractor)
        \item 由固體，轉移到液體\\
          使用浸出(Leaching)器(Leacher)
      \end{itemize}
      \item 將水從成分中移除或加入:
      \begin{itemize}
        \item 使用乾燥(Drying)器(Dryer)將水分從固體中移除
        \item 使用增濕(Humidifying)器(Humidifier)將水分加入氣體中
        \item 使用除溼(Dehumidifying)器(Dehumidifier)將水分從氣體中移除
      \end{itemize}
      \item 固體與固體以密度差分離:
      \begin{itemize}
        \item 使用篩分(Screening)器(Screen)將不同粒徑的固體分離
        \item 使用沉降(Settling)器(Settler)將密度不同的固體分離
      \end{itemize}
    \end{itemize}
    \item 單元之間的串接系統(Piping System): \\
    將不同的單元操作設備連接起來，形成完整的生產流程
    \begin{itemize}
      \item Pumps: 用於輸送液體
      \item Compressors: 用於壓縮氣體
      \item Turbines: 用於從流體中提取能量
      \item Valves: 用於控制流體的流量和壓力
      \item Pipes: 用於連接不同的設備，傳輸流體
      \item Flow Meters: 用於測量流體的流量
      \item Heat Exchangers: 用於在不同流體之間傳遞熱量的設備
    \end{itemize}
    \item 攪拌器(Mixer): 用於混合不同物料的設備
  \end{enumerate}
  \item 若以程序區分，則可以分為:
  \begin{enumerate}
    \item Fluid Flow processes: 涉及流體流動的過程，如管道輸送、泵送等
    \begin{enumerate}
      \item Fluid Transport: 涉及流體的運輸和分配，如管道系統、泵等
      \item Sedimentation: 涉及固體顆粒在流體中的沉降過程，如沉降池等
      \item centifugation: 涉及利用離心力分離不同密度的物質，如離心機等
      \item filtration: 涉及利用過濾介質分離固體和液體，如過濾器等
      \item solids fluidization: 涉及將固體顆粒懸浮在流體中，如流化床等
    \end{enumerate}
    \item Heat Transfer processes: 涉及熱量傳遞的過程，如熱交換器等
    \begin{enumerate}
      \item Heating: 涉及將熱量傳遞給物料以提高其溫度，如加熱器等
      \item Cooling: 涉及從物料中移除熱量以降低其溫度，如冷卻器等
      \item Condensation: 涉及將氣體轉變為液體的過程，如冷凝器等
      \item Evaporation: 涉及將液體轉變為氣體的過程，如蒸發器等
    \end{enumerate}
    \item Mass Transfer processes: 涉及物質傳遞的過程，如蒸餾、吸收等
    \begin{enumerate}
      \item absorption: 涉及將氣體成分吸收進液體中的過程，如吸收塔等
      \item distillation: 涉及將混合物分離成不同組分的過程，如蒸餾塔等
      \item extraction: 涉及將一種物質從混合物中提取出來的過程，如萃取器等
      \item leaching: 涉及將固體中的成分溶解到液體中的過程，如浸出器等
      \item drying: 涉及將水分從物料中移除的過程，如乾燥器等
      \item humidifying: 涉及將水分加入氣體中的過程，如增濕器等
    \end{enumerate}
    \item Thermodynamic processes: 涉及能量轉換和熱力學平衡的過程
    \begin{enumerate}
      \item liquefaction: 涉及將氣體轉變為液體的過程，如液化器等
      \item refrigeration: 涉及將熱量從低溫區域轉移到高溫區域的過程，如冷凍機等
    \end{enumerate}
    \item Mechanical processes: 涉及機械運動和力的過程
    \begin{enumerate}
      \item crushing: 涉及將固體物料破碎成較小顆粒的過程，如破碎機等
      \item sieving: 涉及將固體物料根據粒徑分級的過程，如篩分器等
      \item solid transport: 涉及將固體物料從一個位置運輸到另一個位置的過程，如輸送帶等
    \end{enumerate}
  \end{enumerate}
  \item 根據機制也可以分類成:
  \begin{enumerate}
    \item Size:
    \begin{enumerate}
      \item Sedimentation: 涉及固體顆粒在流體中的沉降過程，如沉降池等
      \item Membrane: 涉及利用半透膜分離不同組分的過程，如膜分離器等
    \end{enumerate}
    \item Phase Change:
    \begin{enumerate}
      \item Distillation: 涉及將混合物分離成不同組分的過程，如蒸餾塔等
      \item Crystallization: 涉及將溶液中的溶質轉變為固體晶體的過程，如結晶器等
    \end{enumerate}
    \item Chemical affinity:
    \begin{enumerate}
      \item Absorption: 涉及將氣體成分吸收進液體中的過程，如吸收塔等
      \item Adsorption: 涉及將氣體或液體成分吸附在固體表面的過程，如吸附器等
      \item Chromatography: 基於不同組分在固定相和流動相中的親和力，如色譜柱等
      \item Ion Exchange: 涉及利用離子交換樹脂分離不同離子的過程，如離子交換器等
      \item Stripping: 涉及將氣體成分從液體中移除的過程，如洗滌塔等
      \item Leaching: 涉及將固體中的成分溶解到液體中的過程，如浸出器等
    \end{enumerate}
    \item Electric field:
    \begin{enumerate}
      \item Electrophoresis: 涉及利用電場分離帶電粒子的過程，如電泳裝置等
      \item Electrolysis: 涉及利用電流引發化學反應的過程，如電解槽等
    \end{enumerate}
    \item Magnetic field:涉及利用磁場分離磁性物質的過程，如磁選機等
    \item Gravity/ Centrifugal force: 涉及利用重力或離心力分離不同密度的物質的過程，如沉降池、離心機等
  \end{enumerate}
  \item 需要考量的因素:
  \begin{itemize}
    \item Feed and product conditions:
    \begin{itemize}
      \item Composition: 物料的組成會影響選擇適合的單元操作
      \item Flow rate: 物料的流量會影響設備的尺寸和操作條件
      \item temperature: 物料的溫度會影響反應速率和分離效率
      \item pressure: 物料的壓力會影響反應速率
      \item phase: 物料的相態會影響選擇適合的單元操作
    \end{itemize}
    \item Property differences that may be exploited:
    \begin{itemize}
      \item Molecular weight: 不同分子量的物質可能需要不同的分離方法
      \item thermaldynamic: 不同熱力學性質的物質可能需要不同的分離方法
      \item transport: 不同傳輸性質的物質可能需要不同的分離方法
    \end{itemize}
    \item Characteristics of operation:
    \begin{itemize}
      \item Ease of scale-up: 單元操作的可擴展性是工業生產中的重要考量因素
      \item physical size limitations: 單元操作的物理尺寸可能會限制其應用範圍
      \item energy requirements: 單元操作的能量需求會影響其經濟效益和環境影響
    \end{itemize}
    \item Economics:
    \begin{itemize}
      \item Capital cost: 單元操作的資本成本會影響其經濟可行性
      \item Operating cost: 單元操作的運營成本會影響其經濟效益
      \item Environmental cost: 單元操作的環境成本會影響其可持續性和社會接受度
    \end{itemize}
  \end{itemize}
\end{itemize}
